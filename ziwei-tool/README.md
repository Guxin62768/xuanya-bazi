# 玄曜 · 紫微斗數命理工具 使用說明

> 網址：https://5fd119c4.strike-agent.com
> 純 HTML/CSS/JS 工具，無需安裝，瀏覽器直接使用。文化娛樂參考用途。

---

## 一、快速開始

1. **公曆排盤（推薦）**：在頂部「公曆生日」輸入出生年月日時、選性別，點「公曆轉農曆排盤」，自動算八字四柱、命盤、五行局並生成完整分析。
2. **手動排盤**：也可在下方手動填年干/年支/農曆月/時/日/五行局/性別，點「安星排盤」。
3. **體驗示例**：選一個示例生辰（浩哥/之子/樣本等），點「填入」快速體驗。

## 三、排盤資訊說明

- **五行局**：水二局（2歲起）、木三局（3歲）、金四局（4歲）、土五局（5歲）、火六局（6歲）
- **大限**：命宮起，10年一限，陽男陰女順行、陰男陽女逆行
- **小限**：男順女逆，1歲起命宮，12年一輪
- **流年太歲**：以流年地支定位宮位
- **十二神煞**：從流年地支起歲建，順行

## 四、進階操作

- **存命盤**：把當前命盤存到本機瀏覽器（localStorage），可載入/刪除
- **複製結果**：一鍵複製完整排盤文本
- **分享**：複製帶參數的分享連結，他人打開自動復現
- **導出報告**：下載完整命理報告（.txt）
- **存PDF**：生成報告HTML並列印為PDF
- **存圖片**：命盤存為PNG
- **主題切換**：右上角太陽圖示切換暗黑/亮色主題
- **導航**：頂部粘性導航，快速跳轉各面板
- **移動端**：手機自動摺疊面板，點標題展開
